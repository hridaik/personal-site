# Personal site

Personal website of Hridai Khurana: resume, projects, and long-form research posts.

Built with React (Create React App), react-router, framer-motion and react-markdown (with KaTeX for math). It is a static frontend with no backend. Interactive demos live in `public/demos`.

## Run locally

```
npm install
npm start
```

## Build

```
npm run build
```

The `build/` folder is a static bundle that can be hosted anywhere (currently AWS S3).
